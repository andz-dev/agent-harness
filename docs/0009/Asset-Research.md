# CC0 asset candidates for the planned city overlays

Question: which planned objects can come from existing CC0 kits, and which must be
generated in code. Only the rows marked "checked" were read on the kit's own page on
2026-10-29. Everything else is a lead to verify before use.

| Need | Candidate | Licence | Status |
|---|---|---|---|
| Ships, boats, harbor craft | Kenney Watercraft Kit (40+ models) | CC0 | checked |
| Factory, chimneys, warehouses | Kenney City Kit (Industrial), 40 models plus solar and wind | CC0 | checked |
| Trains, rail track | Kenney Train Kit (about 50 trains, track) | CC0 | checked; bridges, tunnels and stations are not listed |
| Mountains, rocks, terrain | Kenney Nature Kit | CC0 | lead, contents not read |
| Road tiles, bridges, ramps | Kenney City Kit (Roads) | CC0 | lead, contents not read |
| Cranes, containers | Kenney or Quaternius packs | CC0 | lead |
| Highway pillars, tunnel portal, toll gantry, vault, fence, class signs | generated in code | none | planned |

Rules: new files need a `NOTICE.md` entry; optimise like the existing GLB copies; check the
model works from all four camera rotations.
